# Third-party components

The Windows application bundles a runtime built from Microsoft Build of OpenJDK 17
and the project's OpenJFX 17.0.15 Windows libraries. These components have their own
license terms. Bundling does not change those licenses.

- Microsoft Build of OpenJDK: https://www.microsoft.com/openjdk
- OpenJDK legal material is retained under the packaged runtime's `legal/` folder.
- OpenJFX: https://openjfx.io/
- OpenJFX source and license information: https://github.com/openjdk/jfx/tree/jfx17
- JavaFX dependency artifacts: https://repo.maven.apache.org/maven2/org/openjfx/

The application source and the third-party runtime are separate works. No license
for the application source has been chosen on the author's behalf.
